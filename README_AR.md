# حملة فؤاد — النسخة الخفيفة 2.0

نفس التصميم والألوان وترتيب الصفحة ونوافذ الدعم والتبويبات، مع العربي والإنجليزي ولوحة الإدارة. الواجهة HTML وCSS وJavaScript عادي، والخادم Cloudflare Worker مع D1 وR2.

لا يوجد React أو Next.js أو Vinext أو Vite أو Drizzle أو تثبيت حزم لتشغيل النسخة المحلية. الأيقونات والخطوط والصورة ومولّد QR موجودة داخل الحزمة، ولا تحتاج CDN.

## تشغيل سريع على Windows

1. فك الضغط في **مجلد جديد** وافتح مجلد `fouad-campaign` في VS Code.
2. تحتاج Node.js 22.13 أو أحدث. تحقق بـ`node -v`.
3. افتح الطرفية داخل المجلد ثم:

```powershell
npm run dev
```

افتح http://localhost:5173 . لا تشغّل `npm install` أو pnpm، ولا تحتاج `npm run build` للتشغيل. قاعدة SQLite المحلية تُجهّز تلقائيًا عند أول تشغيل في `.local/`.

وجود كلمة npm هنا فقط لتشغيل أمر محلي؛ لا يُنزّل حزمًا ولا يتصل بسجل npm. تحذير experimental الخاص بـSQLite متوقع في بعض إصدارات Node. لا تفتح index.html مباشرة بوسيلة file://، لأن JavaScript يعمل بوحدات ES ويستخدم API.

## تفعيل لوحة الإدارة محليًا

```powershell
Copy-Item .dev.vars.example .dev.vars
```

افتح `.dev.vars` وأدخل كلمة مرور فريدة بطول 16 محرفًا على الأقل عند `ADMIN_PASSWORD`. لا توجد كلمة مرور افتراضية. أعد تشغيل السيرفر، ثم افتح http://localhost:5173/admin . استخدم localhost، وليس عنوان IP خارجي.

الملف .dev.vars مخصص للأسرار، ومستثنى من Git. لا تشاركه أو تضعه في public.

## الدفع والمحافظ

ربط Payunit محفوظ بنفس تدفق النسخة السابقة وريفو: فاتورة USD، مفتاح Idempotency ثابت للمحاولة، توقيع Webhook مع مهلة زمنية، ثم قراءة حالة الفاتورة من Payunit والتحقق من المبلغ والعملة والبيئة والمرجع.

- `PAYUNIT_MODE=test` افتراضيًا. الدفع التجريبي متاح للأدمن المسجل فقط.
- `PAYUNIT_API_KEY` و`PAYUNIT_WEBHOOK_SECRET` فارغان حتى تدخل إعدادات حسابك.
- لا ننسخ مفاتيح ريفو أو سر Webhook الخاص به إلى الحملة. استخدم إعدادات مستقلة.
- Webhook الإنتاج: `https://YOUR_CAMPAIGN_DOMAIN/api/webhooks/payunit` للأحداث `invoice.paid` و`payment.failed` و`payment.refunded`.
- رجوع الزائر من البوابة لا يؤكد الدفع. صفحة /payment تستعلم عن الحالة الفعلية.
- الحملة مغلقة افتراضيًا، وهدفها صفر حتى توثّق المبالغ وتفتح الاستقبال من الإدارة.
- عناوين USDT وBitcoin فارغة. تضاف من لوحة الإدارة مع الشبكة. يظهر QR محلي دون إرسال العنوان لطرف ثالث.
- التحقق من صيغة عنوان المحفظة ليس إثباتًا لملكيته أو صحة checksum. تأكد منه قبل نشره.
- إجمالي الحملة يعكس دفعات Payunit الحقيقية المؤكدة فقط، ولا يجمع التحويلات الرقمية تلقائيًا. دفعات test والمستردة مستبعدة.

الاختبارات تستخدم محاكاة Payunit فقط. لا توجد مفاتيح أو عمليات مالية حقيقية في الحزمة. تجربة حساب Payunit الفعلي لازمة قبل فتح live.

## الصور والمستندات

تُرفع JPEG وPNG وPDF حتى 5 MB. الرفع يتطلب تأكيد صلاحية الملف للنشر العام. أزل بيانات الهوية والعناوين وأي معلومات حساسة قبل الرفع. الصور الحالية توضيحية.

النسخة المحلية تحفظ البيانات في `.local/campaign.sqlite` والملفات في `.local/uploads/`. تُستبعد من الحزمة وGit، ولا تُرفع تلقائيًا إلى Cloudflare. قواعد البيانات المحلية والحقيقية منفصلة. حذف رابط مستند من اللوحة يخفيه من الصفحة ولا يمحو ملفه من التخزين.

## النشر على حساب Cloudflare الخاص بك

التشغيل المحلي لا يحتاج Wrangler. عند النشر فقط تحتاج تنزيله مرة عبر npx، بما في ذلك أدوات Cloudflare الثنائية. حجم هذا التنزيل باقٍ، لكن حزم Next.js وSWC وكل اعتماديات الواجهة أُزيلت.

1. سجّل الدخول:

```powershell
npx wrangler@4.92.0 login
```

2. أنشئ قاعدة مستقلة للحملة:

```powershell
npx wrangler@4.92.0 d1 create fouad_campaign_db
```

3. انسخ معرّف القاعدة الحقيقي إلى `database_id` في `wrangler.jsonc` بدل العبارة الإرشادية. لا تستخدم `rivo_db`.
4. أنشئ R2 باسم الحزمة؛ هذا يحتاج تفعيل خدمة R2 في حسابك وفق شروطها:

```powershell
npx wrangler@4.92.0 r2 bucket create fouad-campaign-media
```

5. طبّق الترحيلات على قاعدة الحملة فقط:

```powershell
npm run db:remote
```

6. أضف الأسرار من الطرفية؛ يُطلب إدخالها دون كتابتها في الكود:

```powershell
npx wrangler@4.92.0 secret put ADMIN_PASSWORD
npx wrangler@4.92.0 secret put PAYUNIT_API_KEY
npx wrangler@4.92.0 secret put PAYUNIT_WEBHOOK_SECRET
```

7. انشر:

```powershell
npm run deploy
```

راجع اختيار حساب Cloudflare عند كل أمر. اختبر تدفّق Payunit في test على الرابط المنشور وأضف Webhook الصحيح، ثم انتقل إلى live بمفاتيحه وسره وبتعديل PAYUNIT_MODE داخل wrangler.jsonc.

هذه الحزمة لا تغيّر الموقع القديم المنشور تلقائيًا، ولا تنقل بياناته؛ هدفها متابعة التطوير والنشر على حسابك.
